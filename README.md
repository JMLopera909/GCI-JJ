# GCI-JJ

Web application focused on medical appointment scheduling and management, inspired by real healthcare workflows and patient care processes.

## Technologies Used

* C#
* ASP.NET Core
* PostgreSQL
* HTML5
* CSS3
* Bootstrap
* Git & GitHub

## Project Goals

This project is focused on applying backend and frontend development concepts through the implementation of:

* CRUD functionalities
* Database management
* Information validation
* Appointment scheduling workflows
* Healthcare-related operational logic

## Features

* Appointment management system
* Database integration
* Progressive CRUD implementation
* Structured backend logic
* Scalable project structure

## Project Status

Currently in early development stages.

Planned improvements include:

* Authentication and user roles
* Advanced appointment management
* Form validation
* Responsive dashboard
* API integration
